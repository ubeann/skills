# The persuasion line

Persuasion that helps the user reach their own goal belongs in the findings. Persuasion that works against them is a **flag**. Design-education material often teaches both as one toolkit; the audit separates them.

## The four tests

A technique is a flag when it fails any one test. Name the test in the flag.

1. **True.** Every number, timer, stock level, reference price, and progress value reflects something real.
2. **User's goal.** It helps the user do what they came to do, not only what the business wants.
3. **Endorsed.** The user would still accept it if they saw how it works.
4. **Even exit.** Declining takes the same effort as accepting and is worded neutrally.

## Techniques and where they tip over

| Technique | Helps when | Flag when (pattern name) |
|---|---|---|
| Smart default | It is the most common choice, it is visible, and changing it is one tap | It selects the costlier plan, an add-on, or consent the user did not ask for (preselection) |
| Head-start progress | It counts steps the user really finished | The percentage is invented (fake progress) |
| Reference price | The earlier price was real and recent | The crossed-out price never applied (false reference price) |
| Scarcity and urgency | Stock and deadlines are real | The countdown resets, or "only 2 left" is static (fake urgency, fake scarcity) |
| Social proof | The count is real and current | The numbers are made up or never change |
| Loss framing | It states a real consequence the user would want to know about | It threatens the user's own data to force an upgrade |
| Dismiss copy | Neutral ("Not now", "No thanks") | It shames the user for declining ("I'll risk it", "No, I like paying more") (confirmshaming) |
| Highlighted plan | The user can read every plan on equal terms | The other options are hidden, greyed out, or hard to choose (visual interference) |
| Value before signup | The free part is useful by itself | The value is withheld after the user has done the work (results held hostage) |
| Total shown late | Never. Showing the total early always helps | Fees appear only on the final step (hidden costs, drip pricing) |
| Cancellation | As easy as signing up | Signup takes one tap and cancelling needs a call or a maze (roach motel) |

## Writing a flag

Give each flag the screen, the technique, the test it fails, the honest version, and the business risk in one line (complaints, chargebacks, store review rejection, regulators in the user's market). A flag is never in the top fixes as a technique to add, and the report never recommends a flagged technique, even where the source material does.
