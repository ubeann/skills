## Charts and diagrams

- A chart of numbers (bar, line, scatter, heatmap, Sankey, any mark that encodes a value) is the `dataviz` skill, also where `diagram-design` lists the type: its charts are coordinates typed by hand, which no data check covers.
- A diagram of structure (flow, architecture, sequence, state, data model, timeline, swimlane, journey) is the `diagram-design` skill.
- Standing instructions for `diagram-design`: state the plan in one line and draw without waiting for a reply. A project with no `.diagram-design` marker keeps the default style. Font source is `system` when the diagram goes into a report or any file that must open offline.
